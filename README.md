# SLD-Launcher
 A car-focused Android launcher for head units and Android Automotive. Neon or simple dashboard with a live road animation driven by your car's playing cards, a full-screen app popout page, Glass and Classic styles with full colour customisation, and built-in OTA updates (Soon).

What's in it:

Features: real speed counter with gps and in car speedometer connection if your car allows, theres cards for weather and direction using gps, theres a popout page so you can have an app sit within the launcher, Glass and Classic styles, colour customisation, its car-friendly and has a first-run setup.
Requirements and installing: Android 7.0+, and goto settings and default home app and set car launcher as your default home
Popout setup: the adb command in popout turns on freeform windows if your unable to do it in dev options make sure to reboot after the adb command or the dev option toggled for android 10 and below, same with the rounded-corners permission command if display over other apps isnt working for Android Automotive.

Updates: OTA updates are coming.
